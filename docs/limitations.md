# 既知の制約

- 実行確認はmacOSのApple Silicon環境です。Linux、Windows、amd64での再現は未検証です。
- ホストへの公開先を127.0.0.1に限定した、架空データのローカル実験です。HTTPを許可し、walt.idの管理APIは認証を無効にしています。本番向けの認証とTLS設定は含みません。
- 発行者、保有者、検証者を同じPCで動かします。組織間の権限分離やスマホ内の鍵保管は後続回で扱います。
- walt.idのKey Binding JWTなしとProcivisの開示値改ざんは、予定した検査への到達を確認できていません。[結果](results.md)を参照してください。
- Procivisの失敗入力は独自の保有者クライアントで作ります。検証要求の発行者認証や同意画面を備えていないため、このクライアントを実サービスへ流用することは避けてください。
- 信頼する発行者、必須属性、対象コース、申込者名の照合は、OSSの機能と教材が追加した処理を区別して記録しています。氏名の一致だけでは本人確認になりません。
- Procivisはschemaで有効期間を指定するため、期限切れを作る時刻条件が共通fixtureの例と異なります。
- RustのCargo.lock、Pythonの直接依存と間接依存、ベースイメージのdigestを固定しています。ビルド時のaptパッケージまでは固定しておらず、ProcivisのローカルイメージIDが別環境で一致することは保証していません。
- `dc+sd-jwt`とDCQL、各実装のOpenID4VCI/VP経路を使用しています。SD-JWT VCの草案番号との全項目照合、OpenID Foundationの適合性試験や認証取得は行っていません。
- 失効、状態情報の取得失敗、更新、復旧、異なるOSS間の接続、実際の採用判断は今回の対象外です。
- 公開結果には署名付きトークン、鍵、nonce、生ログを載せません。`runtime/`はGitの追跡対象外です。
