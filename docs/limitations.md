# 既知の制約

- この版は比較実験の準備資料です。発行、受領、提示、署名検証を実行するアプリやAPIはありません。
- 共通JSONは署名前の業務データです。SD-JWT VCのシリアライズ例としてそのまま送信できません。
- `example.com`と`.example`の名前は架空の値です。教材のURLは稼働する発行者や検証者ではありません。
- Pythonの整合性確認は入力ファイルの確認です。暗号や製品間の接続を検証しません。
- OSSの版、コンテナ、通信の仕様、署名方式、鍵取得方法は次の実装時に固定します。
- 本人確認、受講の合否、実際の採用判断は実装していません。
- スマホの鍵保管、失効、更新、復旧、異なるOSS間の接続は未検証です。
- 秘密鍵とnonceは将来の実行時に生成する方針であり、準備版には生成処理も含めていません。
