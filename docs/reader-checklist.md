# 各実装回の読者向け完了条件

実装Issueには次の5項目をコピーし、成果物へのリンクと確認結果を添えて完了にします。
下のチェックリストは各回に引き継ぐひな形です。個別の完了状況は[実装Issue](https://github.com/anyoneanderson/did-vc-examples/issues/1)へ記録します。

- [ ] 必要な環境とその版、取得、設定、起動、停止、作成したデータの削除までを記載する。
- [ ] 実行コマンドと成功時の出力例を対応させ、どの処理まで成功したか読者が判断できるようにする。
- [ ] 改ざんや期限切れなど、その回の失敗例と期待する拒否またはエラーを再現できるようにする。
- [ ] 記事公開時のコードをタグで固定し、依存OSSのコミット、コンテナdigest、仕様の版も記録する。
- [ ] サンプルと依存OSSの利用条件、既知の制約、質問と不具合の報告先を記載する。

## タグと記事の対応

準備資料は`preparation-v0.1.0`、実装回は`chapter-03-v1.0.0`のように、目的を区別してタグを付けます。
後者はまだ存在せず、実機検証と記事の準備が終わってから作成します。
記事から固定タグへリンクし、READMEの最新版の手順も案内します。
修正時は新しいタグを付けて差分を記録し、公開済みタグを付け替えません。

公開前には空の作業ディレクトリへcloneし、対象タグのREADMEだけで成功例と失敗例を再現します。
確認したOSとCPU、コマンド、出力、未検証の環境を記録します。
